Features

Everything You Need for Meet Attendance

No logins. No cloud. No hassle. Just open Meet and let the extension handle the rest.

Auto-Tracking on Join

As soon as you join a Google Meet, the extension silently begins tracking participants. No button click needed — it just works.

Full Participant Capture

Automatically opens the People panel and extracts every participant's name. Live preview appears right inside the popup.

Chat Message Capture

Captures the full chat transcript with sender names and timestamps. Department auto-detected from chat for smart sorting.

Program-Wise PDF Reports

Generates separate, formatted PDF attendance sheets sorted by program/department. Perfect for institutional records.

Minimum Duration Filter

Set a minimum attendance duration (default: 40 min). Only participants who stayed long enough are counted as present.

100% Private & Local

All processing happens inside your browser. No servers, no analytics, no API calls. Your data never leaves your machine.

How It Works

Four Steps to a PDF Report

From joining a Meet to a ready-to-submit attendance report in under a minute.

01

Join a Google Meet session

Navigate to any meet.google.com link. The extension detects the session automatically — the popup dot turns green.

02

Auto-tracking begins instantly

The extension watches the People panel and Chat in real time. You'll see the live count in the popup badge.

03

Download your PDF reports

Click "Download Attendance (Program-Wise PDFs)". A formatted attendance PDF is saved to your Downloads folder instantly.

04

Full report with participants + chat

Optionally download the combined Participants + Chat PDF — numbered list, chat messages, timestamps, page numbers.

PDF Reports

What's Inside the Generated PDF

Every PDF is auto-formatted, dated, and ready to submit.

📋 Header Section

Title, meeting date/time, and summary counts — total participants, present, absent.

👥 Participant List

Numbered list with avatar initials, full name, and attendance status. Sorted by department.

💬 Chat Transcript

Full chat log with sender name, timestamp, and message body in a clean card layout.

📄 Page Numbers

Every page is automatically numbered. Filename: MeetReport_YYYY-MM-DD.pdf

Transparency

Why These Permissions?

The extension only requests what it needs. Here's exactly why.

activeTab

Access the active Google Meet tab to read participant and chat data from the DOM.

scripting

Inject content.js into the Meet page to scrape the People panel and Chat panel.

tabs

Detect which tab is the active Meet session so the popup connects to the right tab.

meet.google.com only

Host permission restricted to meet.google.com. Cannot access any other website.

Get Started

Install in 4 Easy Steps

No Chrome Web Store required. Load as an unpacked extension in Developer Mode.

01

Download the Extension

Download the ZIP file and extract the folder to a location you can find easily (e.g., Desktop).

02

Open Chrome Extensions

Open Google Chrome and go to:

chrome://extensions
03

Enable Developer Mode

Toggle Developer Mode ON using the switch in the top-right corner.

04

Load Unpacked Folder

Click "Load unpacked" and select the extracted folder. The icon appears in your toolbar!

Privacy
